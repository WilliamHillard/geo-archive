# GeoArchive

GeoArchive is a personal data analytics project that explores country-level data from around the world.

The long-term goal is to collect data from multiple public sources, store it in a PostgreSQL database, analyze relationships between variables, and build interactive visualizations and AI-powered exploration tools.

Current progress:
- ✅ Project setup and Python environment
- ✅ Database design and setup
- ✅ ETL pipeline for country and population data
- ✅ Integration of additional datasets
- ✅ Data cleaning and transformation
- ✅ Data analysis using SQL
- ✅ SQL views
- 🔄 Power BI dashboard
